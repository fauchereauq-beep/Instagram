# Reprendre le travail dans une nouvelle session

Tout le projet est enregistré sur GitHub (`fauchereauq-beep/Instagram`). Une nouvelle session repart de là, sur une machine neuve.

1. Ouvre une nouvelle session Claude Code sur le dépôt **fauchereauq-beep/Instagram**.
2. Colle ce message :

> Lis CLAUDE.md, BIBLE.md et QUENTIN.md. On reprend les carrousels « Quentin et Brutus ».
> Prochain carrousel : [le format] sur [le thème ou ta situation vécue].
> Propose-moi 3 accroches de couverture, j'en choisis une, puis tu fais le carrousel complet.

3. Pour économiser : un seul carrousel par session courte, et décris ta situation vécue en quelques lignes dès le premier message.
