## 2. La forme : trois formats

| Format | Rôle | Quand |
|---|---|---|
| **Série** (5 épisodes) | Raconter, faire revenir le lendemain | Du lundi au vendredi, une semaine sur deux |
| **Épisode seul** (sitcom ou outil) | Respirer, apprendre un geste | Mardi et jeudi, les semaines calmes |
| **L'énigme du Salève** | Faire jouer, faire commenter | Dimanche, les semaines calmes |

Les séries se publient obligatoirement des jours qui se suivent : chaque épisode annonce « Demain, … ».
Pour les prochains contenus, « Le sage et le singe » rejoint « La boîte à outils » : un sage est un outil parmi d'autres.

## 7. Comment publier

- Une séance par semaine, le dimanche, pour programmer toute la semaine d'un coup.
- Dans Instagram, avec un compte professionnel : nouvelle publication → sélection multiple → planches 01 à 08 dans l'ordre → légende → **Paramètres avancés → Programmer cette publication**.
- Toujours la même heure de publication. Pour la choisir : Tableau de bord → Statistiques → Audience, l'heure où tes abonnés sont le plus en ligne.
